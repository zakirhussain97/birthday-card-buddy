# Birthday Card Buddy

A small web app that helps you write funny birthday cards. Give it a name, age, and hobby, and it generates a playful birthday message and shows it on a virtual card.

## Features

- Enter a person’s name, age, and hobby.
- Generates a lighthearted, funny birthday message based on the inputs.
- Festive page styling with a fun, colorful birthday theme.
- Card appears on the right side of the page, styled like the inside of a birthday card.
- New cards do not replace old ones; each new card is stacked underneath the previous cards.
